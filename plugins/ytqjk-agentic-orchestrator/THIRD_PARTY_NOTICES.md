# Third-party notices

## Caveman skill

YTQJK bundles an adapted Codex-compatible copy of Matt Pocock's historical
[`caveman` skill](https://github.com/mattpocock/skills/blob/221ffca96736afefdc08ca7cf0b3965e9ea83f41/skills/productivity/caveman/SKILL.md).
The behavior text is preserved; frontmatter and attribution were adapted for this
plugin. Upstream removed `caveman` after that revision, so YTQJK carries the audited
snapshot instead of depending on a moving install target.
